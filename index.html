📜 كيف تلعب

الحركة: WASD أو الأسهم / عصا اللمس. الفأرة أو السحب لتدوير الكاميرا.

الركوب: اقترب من الحصان واضغط R أو زر 🐎. وأنت راكب: Shift للعدو.

التصويب: انقر أو زر 🔥 للإطلاق. Q = عين الصقر (إبطاء الوقت). B = المنظار.

التفاعل: E أو زر «تفاعل» عند ظهوره. C = انحناء (تسلل). F = ضمادة. J = دفتر سليم. Esc = إيقاف.

المشاهد السينمائية: ضغطة على «تخطَّ» = اللقطة التالية، ضغطة مطوّلة = تخطي المشهد كله. الاختيارات لا تُتخطَّى أبدًا.

الحفظ: تلقائي عند كل نقطة تفتيش والنوم في المخيم ونهاية كل فصل.
